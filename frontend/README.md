# Sales Dashboard – React Frontend

A modern and responsive Sales Dashboard built using **React, TypeScript, Material UI, and ECharts**, integrated with a NodeJS backend API.

---

## 🚀 Features

### Required Tasks Implemented
- Fetch and display list of states from NodeJS API  
- State selection dropdown with first state selected by default  
- Fetch minimum and maximum order dates for selected state  
- Date range selection (From – To)  
- Fully functional dashboard UI based on Figma design  

### Bonus Tasks Implemented
- Dynamic API integration for:
  - Dashboard cards  
  - All charts and visualizations  
- Expand / Collapse sidebar navigation  
- Light / Dark theme toggle  
- Fully responsive layout  
- Built completely using **TypeScript**

---

## 🛠 Technologies Used

- **ReactJS + TypeScript** – Frontend framework  
- **Material UI (MUI)** – UI components  
- **ECharts** – Data visualization  
- **Axios** – API calls  
- **Custom React Hooks** – Logic separation  
- **Responsive Design**

---
## 🌍 Environment Variables

This project uses an environment variable to configure the backend API base URL.

## 📦 Prerequisites

Make sure you have installed:

- Node.js (v14 or higher)
- npm or yarn
- Backend API running (NodeJS server)
